# 🧑‍💻 Builder pack

For whoever owns the repo — where GitHub sends forty emails a day and the one that matters looks exactly like the thirty-nine that don't.

**How to read the marks**: ✅ install today · 🔨 build it with Claude ("build me the …") · 🌠 a wish for now.

| Routine | Why it's in the pack | Status |
|---|---|---|
| **CI-noise compactor** — the day's automated CI/bot emails auto-archived into one honest line ("18 runs, 2 genuinely red: …") | Cry-wolf subjects train you to ignore your own alarms; this un-trains it. Born from a real mirror that found ~40/day | 🔨 |
| **PR queue digest** — what awaits *your* review, what's gone stale, which first-time contributor is waiting | Review debt is invisible until someone gives up | 🔨 * |
| **Dependency & release watch** — new versions and breaking changes in *your actual stack* | Reading every changelog is a job; being surprised by a breaking change is worse | 🔨 |
| **Issue gardener** — weekly read-only report: aging issues, unanswered questions on your open-source repos | The garden grows weeds at exactly the rate you stop looking | 🔨 |
| [🧰 Kit news](../routines/kit-news/ABOUT.md) | You of all people will want to see what other builders contribute | ✅ |

\* **The one setup note that matters**: routines that read your *private* work repo need it added as a source when scheduling, and the Claude GitHub app needs access to it — the same one-time grant [described here](../GETTING-STARTED.md#step-3--open-your-copy-with-claude-code). Public repos need nothing.

**Choosing your method power-up**: engineering-craft skills for the builds above live on the [power-ups shelf](../docs/power-ups.md) — gstack for the whole factory, Superpowers for the discipline. Opinionated guidance is there; nothing installs by default.
