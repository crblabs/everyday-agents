# The helpers' notebook

Each routine appends its run log here (`email-triage-log.md`, `watchlist-log.md`, …) and the weekly review writes its recaps here. You never *have* to read any of it — but it means "what have my helpers been doing?" always has an exact, dated answer.

A missing entry where a run should be is how problems get caught: the weekly review and the checkup both look for gaps.
