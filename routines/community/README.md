# The community shelf

Routines contributed by people who use the kit — each one built for a real life, scrubbed of its builder's personal details, **and read line by line by a human** against the [public checklist](../../CONTRIBUTING.md) before landing here. Every routine carries its contributor's credit.

Installing one is a conversation: say **"what's new?"** to Claude in your copy, and it will show you what's here, tell you it came from this shelf, and set it up for you.

*The shelf is new — the first gift could be yours. Built something you're a little proud of? Say "share my routine".*
